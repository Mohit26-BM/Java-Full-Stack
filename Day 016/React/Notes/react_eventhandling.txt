1. WHAT IS AN EVENT?
--------------------
An event is an action or occurrence detected by the browser. Examples include:

- Clicking a button
- Typing or changing an input
- Submitting a form
- Selecting an option
- Pressing a keyboard key
- Moving the pointer over an element
- Focusing or leaving an input

React lets a component respond to these events by passing a function to a
JSX event prop.

Common React event props:
- onClick
- onChange
- onInput
- onSubmit
- onKeyDown
- onKeyUp
- onMouseEnter
- onMouseLeave
- onFocus
- onBlur
- onDoubleClick
- onCopy

<button onClick={ showAlert } >Click</button>
<div onClick={showAlert}>Click Para</div>

function showAlert(){
	alert("Alert messge is called");
}

React event props use camelCase. For example, use onClick rather than onclick.

2. HOW EVENT HANDLING WORKS
---------------------------
The basic pattern is:

function handleClick() {
  console.log("Clicked!");
}

() => console.log("clicked!");


<button onClick={() => console.log("clicked!");}>Click me</button>

When the user clicks the button, React invokes handleClick.

Important:
CORRECT:   onClick={handleClick}
USUALLY WRONG: onClick={handleClick()}

The second version calls handleClick while React is rendering. To pass
arguments, use an arrow function:

<button onClick={() => handleDelete(10)}>Delete</button>

The arrow function is called on the click, and it then calls handleDelete(10).

3. EXAMPLE: SIMPLE CLICK EVENT
------------------------------
function ClickExample() {
  function handleClick() {
    alert("The button was clicked!");
  }

  return (
    <div>
      <h2>React Click Event</h2>
      <button onClick={handleClick}>Click Me</button>
    </div>
  );
}

export default ClickExample;

Explanation:
- handleClick is a JavaScript function.
- onClick registers the function as the click handler.
- React calls the handler when the user clicks.
- The alert is only for demonstration; applications often update state instead.

9. EXAMPLE: TEXT INPUT WITH onChange
------------------------------------
import { useState } from "react";

function NameInput() {
  const [name, setName] = useState<string>("");

  return (
    <div>
      <label>
        Your name:
        <input
          value={name}
          onChange={event => setName(event.target.value)}
          placeholder="Enter your name"
        />
      </label>
      <p>Hello, {name || "Guest"}!</p>
    </div>
  );
}

This is a controlled input: React state controls the value shown in the input.
When the user types, onChange updates state, and React renders the new value.

10. EXAMPLE: A TYPED CHANGE HANDLER
-----------------------------------
import { useState } from "react";
import type { ChangeEvent } from "react";

function EmailInput() {
  const [email, setEmail] = useState<string>("");

  function handleEmailChange(event: ChangeEvent<HTMLInputElement>) {
    setEmail(event.target.value);
  }

  return (
    <div>
      <label>
        Email:
        <input type="email" value={email} onChange={handleEmailChange} />
      </label>
      <p>Current email: {email}</p>
    </div>
  );
}

TypeScript often infers event types in inline handlers. Explicit types are
useful for named reusable functions. Use ChangeEvent<HTMLTextAreaElement> for
textarea and ChangeEvent<HTMLSelectElement> for select elements.

15. EXAMPLE: FORM SUBMISSION
----------------------------
import { useState } from "react";
import type { FormEvent } from "react";

function LoginForm() {
  const [username, setUsername] = useState<string>("");
  const [message, setMessage] = useState<string>("");

  function handleSubmit(event: FormEvent<HTMLFormElement>) {
    event.preventDefault();
    setMessage(`Form submitted for ${username || "unknown user"}.`);
  }

  return (
    <form onSubmit={handleSubmit}>
      <label>
        Username:
        <input
          value={username}
          onChange={event => setUsername(event.target.value)}
        />
      </label>
      <button type="submit">Submit</button>
      <p role="status">{message}</p>
    </form>
  );
}

event.preventDefault() prevents the browser's default form submission, which
would normally navigate or reload the page. A real application should validate
the data and submit it to an API.

16. EXAMPLE: SIMPLE FORM VALIDATION
-----------------------------------
import { useState } from "react";
import type { FormEvent } from "react";

function EmailValidation() {
  const [email, setEmail] = useState<string>("");
  const [message, setMessage] = useState<string>("");

  function handleSubmit(event: FormEvent<HTMLFormElement>) {
    event.preventDefault();

    if (!email.trim().includes("@")) {
      setMessage("Please enter an email address containing @.");
      return;
    }

    setMessage("The basic email check passed.");
  }

  return (
    <form onSubmit={handleSubmit}>
      <label>
        Email:
        <input
          type="email"
          value={email}
          onChange={event => setEmail(event.target.value)}
        />
      </label>
      <button type="submit">Validate</button>
      <p role="status">{message}</p>
    </form>
  );
}

This is a small teaching check, not comprehensive email validation.

21. EVENT BUBBLING
------------------
When an event occurs on a nested element, it commonly bubbles up through
ancestor elements. A click on a button inside a clickable div can trigger both
the button's handler and the div's handler.

EXAMPLE:
function BubblingExample() {
  return (
    <div
      onClick={() => alert("Parent clicked")}
      style={{ padding: 24, border: "1px solid gray" }}
    >
      <button onClick={() => alert("Button clicked")}>
        Click me
      </button>
    </div>
  );
}

Click the button and both alerts may appear: first the button handler, then
the parent handler.

22. STOP EVENT PROPAGATION
--------------------------
function StopPropagationExample() {
  return (
    <div
      onClick={() => alert("Parent handler")}
      style={{ padding: 24, border: "1px solid gray" }}
    >
      <button
        onClick={event => {
          event.stopPropagation();
          alert("Button handler only");
        }}
      >
        Stop bubbling
      </button>
    </div>
  );
}

stopPropagation() prevents the event from reaching ancestor handlers. Use it
only when that behaviour is intended.

23. PREVENT DEFAULT BROWSER BEHAVIOUR
-------------------------------------
function PreventDefaultExample() {
  return (
    <a
      href="https://example.com"
      onClick={event => {
        event.preventDefault();
        alert("Navigation was prevented.");
      }}
    >
      Click this link
    </a>
  );
}

preventDefault() stops the browser's default action, such as following a link
or performing the normal form submission.

Difference:
- stopPropagation(): controls whether the event bubbles to ancestors.
- preventDefault(): prevents the browser's default action.
They solve different problems.

25. WHAT IS LIST RENDERING?
---------------------------
List rendering means displaying repeated UI from an array. JavaScript's map()
method transforms each array item into JSX.

General pattern:
items.map(item => <li key={item.id}>{item.name}</li>)

A key helps React match list items between renders. Prefer stable unique IDs,
such as database IDs. Keys must be unique among siblings, not necessarily
across the entire application.

26. EXAMPLE: SIMPLE STRING ARRAY
--------------------------------
function FruitList() {
  const fruits: string[] = ["Apple", "Banana", "Mango", "Orange"];

  return (
    <div>
      <h2>Fruits</h2>
      <ul>
        {fruits.map(fruit => <li key={fruit}>{fruit}</li>)}
      </ul>
    </div>
  );
}

The fruit string is a reasonable key here because each value is unique.
If duplicates are possible, use objects with unique IDs.

import { useState } from "react";

interface SearchProduct {

      )}

34. EXAMPLE: ADD AN ITEM
------------------------
import { useState } from "react";

interface Task {
  id: number;
  title: string;
}

function AddTask() {
  const [tasks, setTasks] = useState<Task[]>([
    { id: 1, title: "Learn JSX" },
    { id: 2, title: "Learn props" }
  ]);
  const [title, setTitle] = useState<string>("");

  function addTask() {
    const trimmedTitle = title.trim();
    if (!trimmedTitle) return;

    setTasks(previous => [
      ...previous,
      { id: Date.now(), title: trimmedTitle }
    ]);
    setTitle("");
  }

  return (
    <div>
      <input
        value={title}
        onChange={event => setTitle(event.target.value)}
        placeholder="New task"
      />
      <button onClick={addTask}>Add task</button>
      <ul>{tasks.map(task => <li key={task.id}>{task.title}</li>)}</ul>
    </div>
  );
}

The spread syntax creates a new array. Date.now() is acceptable for a small
demo, but a backend-generated ID or robust ID generator is better in production.

36. EXAMPLE: UPDATE AN ITEM
---------------------------
import { useState } from "react";

interface Task {
  id: number;
  title: string;
  completed: boolean;
}

function ToggleTaskCompletion() {
  const [tasks, setTasks] = useState<Task[]>([
    { id: 1, title: "Learn React", completed: false },
    { id: 2, title: "Practice TypeScript", completed: false }
  ]);

  function toggleTask(id: number) {
    setTasks(previous =>
      previous.map(task =>
        task.id === id
          ? { ...task, completed: !task.completed }
          : task
      )
    );
  }

  return (
    <ul>
      {tasks.map(task => (
        <li key={task.id}>
          <label>
            <input
              type="checkbox"
              checked={task.completed}
              onChange={() => toggleTask(task.id)}
            />
            {task.completed ? <s>{task.title}</s> : task.title}
          </label>
        </li>
      ))}
    </ul>
  );
}

Use map() to make a new array and the object spread syntax to create a new
object for the item that changes. Do not mutate state directly.

38. EXAMPLE: TODO CHECKLIST
---------------------------
import { useState } from "react";

interface Todo {
  id: number;
  title: string;
  done: boolean;
}

function TodoChecklist() {
  const [todos, setTodos] = useState<Todo[]>([
    { id: 1, title: "Read documentation", done: false },
    { id: 2, title: "Write a component", done: true },
    { id: 3, title: "Practice events", done: false }
  ]);

  function toggleTodo(id: number) {
    setTodos(previous =>
      previous.map(todo =>
        todo.id === id ? { ...todo, done: !todo.done } : todo
      )
    );
  }

  const completedCount = todos.filter(todo => todo.done).length;

  return (
    <div>
      <h2>Todo List</h2>
      <p>Completed {completedCount} of {todos.length}</p>
      {todos.map(todo => (
        <label key={todo.id} style={{ display: "block" }}>
          <input
            type="checkbox"
            checked={todo.done}
            onChange={() => toggleTodo(todo.id)}
          />
          {todo.done ? <s>{todo.title}</s> : todo.title}
        </label>
      ))}
    </div>
  );
}

Create ProductManager.tsx:

import { useState } from "react";

interface Product {
  id: number;
  name: string;
  category: string;
  quantity: number;
}

export default function ProductManager() {
  const [products, setProducts] = useState<Product[]>([
    { id: 101, name: "Laptop", category: "Electronics", quantity: 10 },
    { id: 102, name: "Mobile", category: "Electronics", quantity: 0 },
    { id: 103, name: "Chair", category: "Furniture", quantity: 3 }
  ]);

  const [name, setName] = useState<string>("");
  const [category, setCategory] = useState<string>("General");
  const [quantity, setQuantity] = useState<string>("1");
  const [search, setSearch] = useState<string>("");

  function addProduct() {
    const cleanName = name.trim();
    const parsedQuantity = Number(quantity);

    if (!cleanName) {
      alert("Enter a product name.");
      return;
    }

    if (
      quantity.trim() === "" ||
      !Number.isInteger(parsedQuantity) ||
      parsedQuantity < 0
    ) {
      alert("Quantity must be a non-negative whole number.");
      return;
    }

    const product: Product = {
      id: Date.now(),
      name: cleanName,
      category: category.trim() || "General",
      quantity: parsedQuantity
    };

    setProducts(previous => [...previous, product]);
    setName("");
    setCategory("General");
    setQuantity("1");
  }

  function removeProduct(id: number) {
    setProducts(previous => previous.filter(product => product.id !== id));
  }

  const filteredProducts = products.filter(product =>
    `${product.name} ${product.category}`
      .toLowerCase()
      .includes(search.toLowerCase())
  );

  return (
    <main>
      <h1>Product Manager</h1>

      <section>
        <h2>Add Product</h2>

        <label>
          Name:
          <input
            value={name}
            onChange={event => setName(event.target.value)}
            placeholder="Product name"
          />
        </label>

        <label>
          Category:
          <input
            value={category}
            onChange={event => setCategory(event.target.value)}
          />
        </label>

        <label>
          Quantity:
          <input
            type="number"
            min="0"
            step="1"
            value={quantity}
            onChange={event => setQuantity(event.target.value)}
          />
        </label>

        <button onClick={addProduct}>Add Product</button>
      </section>

      <section>
        <h2>Search Products</h2>
        <input
          value={search}
          onChange={event => setSearch(event.target.value)}
          placeholder="Search name or category"
        />
      </section>

      <section>
        <h2>Product List</h2>

        {filteredProducts.length === 0 ? (
          <p>No matching products found.</p>
        ) : (
          <table border={1} cellPadding={8}>
            <thead>
              <tr>
                <th>ID</th>
                <th>Name</th>
                <th>Category</th>
                <th>Quantity</th>
                <th>Stock Status</th>
                <th>Action</th>
              </tr>
            </thead>
            <tbody>
              {filteredProducts.map(product => (
                <tr key={product.id}>
                  <td>{product.id}</td>
                  <td>{product.name}</td>
                  <td>{product.category}</td>
                  <td>{product.quantity}</td>
                  <td>
                    {product.quantity === 0
                      ? "Out of stock"
                      : product.quantity < 5
                        ? "Low stock"
                        : "In stock"}
                  </td>
                  <td>
                    <button onClick={() => removeProduct(product.id)}>
                      Remove
                    </button>
                  </td>
                </tr>
              ))}
            </tbody>
          </table>
        )}

        <p>Total products: {products.length}</p>
        <p>Matching products: {filteredProducts.length}</p>
      </section>
    </main>
  );
}

============================================================
PART 9 — IMPORTANT LIST CONCEPTS
============================================================

1. map()
------
Transforms every array element into JSX.

items.map(item => <li key={item.id}>{item.name}</li>)

2. filter()
-----------
Returns a new array containing only matching elements.

const available = products.filter(product => product.quantity > 0);

3. find()
--------
Returns the first matching element, or undefined if there is no match.

const product = products.find(item => item.id === selectedId);

4. sort()
---------
Orders array elements, but mutates the array. Copy first if needed.

const sorted = [...names].sort((a, b) => a.localeCompare(b));

5. slice()
----------
Returns a selected portion of an array, often used for pagination.

const visible = products.slice(0, 5);

6. KEYS
-------
Use a stable ID:
<li key={product.id}>{product.name}</li>

Avoid using array indexes as keys when items may be added, removed, filtered,
or reordered. Do not use Math.random() as a key during rendering. A key is used
by React to identify siblings; it is not automatically passed as a normal prop.

7. IMMUTABLE STATE UPDATES
--------------------------
Add:
setItems(previous => [...previous, newItem]);

Remove:
setItems(previous => previous.filter(item => item.id !== id));

Update:
setItems(previous =>
  previous.map(item =>
    item.id === id ? { ...item, active: !item.active } : item
  )
);

Do not call previous.push(newItem) or modify an object in state directly.

============================================================
PART 10 — COMMON MISTAKES
============================================================

MISTAKE 1: Calling a handler during render
Wrong:   <button onClick={saveData()}>Save</button>
Correct: <button onClick={saveData}>Save</button>

MISTAKE 2: Passing an argument incorrectly
Wrong:   <button onClick={removeProduct(product.id)}>Remove</button>
Correct: <button onClick={() => removeProduct(product.id)}>Remove</button>

MISTAKE 3: Missing list key
Wrong:   products.map(product => <li>{product.name}</li>)
Correct: products.map(product => <li key={product.id}>{product.name}</li>)

MISTAKE 4: Mutating an array in state
Wrong:
products.push(newProduct);
setProducts(products);

Correct:
setProducts(previous => [...previous, newProduct]);

MISTAKE 5: Reading a checkbox's value instead of checked
Usually correct:
onChange={event => setAccepted(event.target.checked)}

MISTAKE 6: Forgetting preventDefault on a custom form handler
If you want to handle submission without browser navigation, call
event.preventDefault() in the onSubmit handler.

MISTAKE 7: Using an unstable list key
Avoid key={Math.random()} and avoid indexes for changing/reorderable lists.
Use a stable unique identifier.

MISTAKE 8: Updating state based on an old value
Prefer:
setCount(previous => previous + 1)
when the new value depends on the previous state.

SUMMARY
============================================================

EVENT HANDLING
- onClick: respond to clicks
- onChange: respond to input changes
- onSubmit: handle form submission
- onKeyDown: respond to keyboard keys
- onMouseEnter/onMouseLeave: pointer entry and exit
- onFocus/onBlur: focus changes
- preventDefault(): prevent the browser's default action
- stopPropagation(): stop an event from bubbling to ancestors

LISTS
- map(): render each item
- filter(): select matching items
- find(): find one item
- sort(): order a copied array
- slice(): select a range
- key: stable identity for list items
- useState: hold interactive list data
- spread/map/filter: update arrays immutably
