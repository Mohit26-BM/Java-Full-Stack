Lambda Expression - It is an anonymous methods without having
1. name of the method
2. return type of the method
3. access specifier of the method

public int add(int a, int b){
	return a+b;
}

(int a, int b) -> {
	return a+b;
}

Simplied:
1.  In lambda expression datatype for parameters are not required


(a,b) -> {

	return a+b;
}

2. Paranethesis is not required if there is only one line in the block

(a,b) -> return a+b;

3. In lambda expressions if there is only one return statement, then return keyword is also
not required

(a,b) -> a+b;
