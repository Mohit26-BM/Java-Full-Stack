Spring - java based framework for developing web applications
Spring relies on two basic principles

1. Dependency Injection (DI) - The process of injecting the
dependent beans

2. Inversion of Control (IoC) - Delegation of dependent object
creation to the third party container



Beans -- A java object managed by spring container

In spring confg, is provided in 3 ways

1. xml file  - Xml file -> Completely deprecated

2. Java class -- java class

3. Java Annoations


Container -- BeanFactory (I) ( Life Cycle methods of Beans,

Scope - referes to the no instances that were created

1. singleton -- only instance for any no of calls
2. prototype -- every time a new instance is created
3. request -- for every http request a new instance is created
4. session - for every new session it will create a new instance
5. application -- for every new application context it will create a new
instance

select the required version (jdk17) --> click finish --> apply --> apply and close
